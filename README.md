# Hi, I'm Kay 👋

I'm a biomedical researcher building reproducible software and workflows for physiological, clinical, and genomic data. My research interests include high-altitude physiology and machine learning for biomedical time series.

## Selected work

### Cognitio

[![Cognitio](https://raw.githubusercontent.com/kvongruenigen/cognitio/main/assets/cognitio-lockup-dark.png)](https://kvongruenigen.github.io/cognitio/play/)

Cognitio is an offline desktop app for running ten cognitive tasks covering attention, memory, executive function, and response speed. It supports configurable sessions, local participant records, and CSV and PDF exports.

[![Try Cognitio in your browser](https://img.shields.io/badge/Try_Cognitio_in_your_browser-5145CD?style=for-the-badge&logoColor=white)](https://kvongruenigen.github.io/cognitio/play/)
[![Latest Cognitio desktop release](https://img.shields.io/github/v/release/kvongruenigen/cognitio?style=for-the-badge&label=Desktop%20release&logo=github&color=374151)](https://github.com/kvongruenigen/cognitio/releases/latest)
[Repository](https://github.com/kvongruenigen/cognitio)

- [Vitals Explorer](https://github.com/kvongruenigen/vitals-explorer) is a Python desktop app for plotting wearable vital signs, checking data quality, and exporting measurements. [See plots from the synthetic demo](https://github.com/kvongruenigen/vitals-explorer#screenshots).
- [maf4pgx](https://github.com/kvongruenigen/maf4pgx) documents a workflow for bringing cancer mutation data into Progenetix so researchers can study sequence variants alongside copy number changes. [View the workflow diagram](https://github.com/kvongruenigen/maf4pgx/blob/main/README.md#workflow).
